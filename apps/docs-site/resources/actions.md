# Actions

Actions are interactive elements that perform operations on your records.

## Action Types

- **Modal Actions** - Open in a modal window
- **Slide-over Actions** - Slide in from the screen edge
- **Inline Actions** - Render directly in the UI

## Prebuilt Actions

- Create
- Edit
- View
- Delete
- Restore (for soft deletes)
- Force Delete
