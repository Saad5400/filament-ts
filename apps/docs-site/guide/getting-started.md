# Getting Started

Welcome to Filament TypeScript! This guide will help you get up and running quickly.

## Choose Your Path

- **New Project**: Start from scratch with a fresh installation
- **Existing Project**: Add Filament to an existing application

## New Project

The fastest way to start is using our CLI:

```bash
npx filament-ts init my-admin-panel
cd my-admin-panel
pnpm install
pnpm dev
```

This creates a new project with:
- Filament configured and ready to use
- Example resources to explore
- Authentication set up
- Beautiful default styling

## Existing Project

For existing projects, follow the [Installation](/guide/installation) guide.
